## Logging standard

For each material entry capture, where applicable: date/version, unique ID, context/problem, change/decision, rationale, evidence/source, assumptions, dependencies, alternatives considered, risks, validation, owner/status and follow-up.

Project-specific conversation details are not part of the repository log. Logs record implementation/evidence only.
